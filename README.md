
# Inventory Movement Dashboard ui Honeywell L1

A full-stack web application for visualizing warehouse stock movements with interactive charts and data export capabilities.

## Tech Stack

**Backend:** Spring Boot 3.2, Java 17   
**Data:** JSON-based mock data (3000+ records)

## Features

✓ Date range and movement type filtering  
✓ Paginated table (10 rows/page)  
✓ Pie chart for IN/OUT distribution  
✓ Time-series chart for daily trends  
✓ CSV export of filtered data  
✓ Responsive design

## Quick Start

### Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

Server runs on `http://localhost:8080`
